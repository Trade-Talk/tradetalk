🎨 TradeTalk Logo Setup

What You Need:

  • ✅ Your logo image (the blue arrow with "1")
  • ✅ Image editing tool (Photoshop, Figma, Canva, or online tool)
  • ✅ 5 minutes of your time

Step 1: Prepare Your Logo (1024x1024 PNG)

You need to export your logo as a 1024x1024 PNG file:

  • Size: Exactly 1024x1024 pixels
  • Format: PNG (with or without transparency)
  • Background: Blue (#2563eb) or transparent
  • File name: icon.png

Quick Online Tools:

  • Canva - Easy to use
  • Photopea - Free Photoshop alternative
  • Squoosh - Image resizer

Step 2: Save in Correct Location

Place your icon.png file here:

tradetalk/v2-social-hybrid/resources/icon.png

Replace the existing icon.svg file in that folder.

Step 3: Generate Icons

Open Terminal and run:

cd /Users/dhwanibalchandani/Developer/tradetalk/v2-social-hybrid
npm run generate-icons

This will create all the iOS icon sizes automatically!

Step 4: Build & Open in Xcode

npm run ios:build
npm run ios:open

Your app will open in Xcode with the new icon! 🎉
